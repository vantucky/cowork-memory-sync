# cowork-memory-sync

Private snapshot store for Cowork space conversations.

Each linked Cowork space pushes structured conversation snapshots here, organized as `snapshots/<alias>/<YYYY-MM-DD>-<slug>.md`. Snapshots auto-expire after 30 days.

Managed by the [`cowork-memory-sync` plugin](https://github.com/vantucky/custom-plugins/tree/main/cowork-memory-sync).
